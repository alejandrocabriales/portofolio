# Design — Manuel Cabriales

## Direction

Hand-drawn sketchbook, following the user's illustration reference (20 November 2026): near-white paper, 2px ink strokes with wobbly radii, mint and orange marker accents, handwritten display type, orange hand-drawn underline. Supersedes the cream/terracotta editorial direction. Factual content and English copy from PRODUCT.md unchanged.

## Tokens

`src/styles/global.css` final token block ("Sketchbook") is the source. Primitives: `--wobble`, `--wobble-2`, `--wobble-pill` (irregular border-radius), `--sketch-w`, utilities `.sketch-box`, `.sketch-pill`, `.hand-underline`.

## Typography

Display and UI labels (headings, nav, buttons, dates): Kalam 400/700 (@fontsource/kalam). Body: Archivo. Tech labels: Martian Mono. Section headings sit in rotated orange pills; links use wavy orange underlines.

## Composition

64rem shell with fluid 1.25–3rem gutters. Quiet wordmark and text navigation. A left-aligned introductory claim and contact actions face a small geometric code emblem. Home sequence: introduction, Experience, Stack, Writing, Selected work, Contact. Pale section numerals reproduce the reference’s visual organization. Work remains linked to the existing case-study routes; published posts remain real articles rather than placeholders.

Experience uses a date column beside the company, position, summary, outcomes and technology labels. Stack groups remain labeled. Article cards use a paper surface and a thin border. Contact is compact with email and verified social links.

## Responsive behavior

At 40rem, the navigation links form a second row, the code emblem disappears, and experience, stack groups and contact stack vertically. Article grids use minmax(0, 1fr) tracks via an auto-fit minimum. Root overflow uses clip. Buttons and navigation labels stay on one line.

## Interaction and accessibility

Preserve working theme toggle, pre-paint theme resolution, skip link and visible focus rings. Links change accent or underline on hover. Primary actions have a 44px minimum height. No decorative entrance animation. Existing reduced-motion support remains. Availability comes from AVAILABILITY, and factual claims come from existing data.

## Scope

Home, shared shell, blog index, articles (prose h2 hand-drawn rule, sketch-framed code and figures, mint tag chips), case studies (mint sketch card header, orange measured block, pill block labels), 404 and contact nudge all follow the sketchbook direction. Social cards, favicon and raster icons are regenerated by `pnpm og` with the sketch template (Chalkboard SE stands in for Kalam because librsvg only reads system fonts). `ProjectCard` and `FlightRecord` are unused legacy components and were not restyled.

## Validation

Production build and Astro diagnostics pass. Rendered with Playwright at 1280px and 390px, light and dark: home, blog index, article, case study, 404 — no horizontal overflow.
